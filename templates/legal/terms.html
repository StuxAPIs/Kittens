Terms and Ethics

The Kittens API is a free, public service that returns random kitten images. By using it, you agree to the following:

Fair use

Don't hammer the API with excessive automated requests. Reasonable personal and hobby-project use is fine; if your traffic looks like it's trying to take the service down, we'll rate-limit or block it.

No warranty

The API is provided "as is", with no uptime guarantee. It's a free side project, not a paid SLA-backed service.

Image rights

Images served through this API are used for a non-commercial hobby project. If you believe an image is yours and shouldn't be here, contact us (see Imprint) and we'll remove it.
